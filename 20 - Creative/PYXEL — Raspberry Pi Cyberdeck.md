# PYXEL — Raspberry Pi 5 Cyberdeck

> Handheld cyberdeck built on Raspberry Pi 5. Terminal-native environment for Python and AI learning. Personal hardware project — educational tool and artifact.

---

## Concept

A pocket-sized, purpose-built learning machine. Not a general-purpose computer — a cyberdeck optimized for:
- Terminal-native Python development
- AI/ML experimentation (local models, API calls)
- Intentional, distraction-free computing

Name: **PYXEL** — pixel + Python, with a retro-terminal aesthetic implied.

## Software / environment

- OS: Raspberry Pi OS (headless or lite + minimal desktop)
- Shell: bash / zsh, terminal-first
- Python: 3.x, virtualenvs
- AI tooling: Anthropic API, local model experiments (Ollama or similar)

---

## Curriculum design

Structured learning path built around the device:

1. Terminal fluency — navigation, file ops, piping
2. Python fundamentals — variables, functions, loops, data structures
3. File I/O and automation scripts
4. APIs — calling Anthropic, parsing JSON, building small tools
5. Local AI — running small models, prompt engineering at the terminal
6. Project: build something real on the device

*Curriculum designed to be completable on PYXEL itself — no browser, no IDE crutch.*
