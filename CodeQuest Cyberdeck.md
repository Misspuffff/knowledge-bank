# CodeQuest

> JavaScript learning app. Built in Claude Code across 10 sessions. React / Vite / Tailwind / Supabase stack.

---

## What it is

A structured, gamified JavaScript learning app — built for people who want to actually understand code, not just copy-paste it. Designed around progressive challenges with immediate feedback.
